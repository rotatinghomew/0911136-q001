# 领域资料与供数约定

## 数据含义

坐标为局地等面积平面米，村域为不重叠轴对齐矩形。雨量为 start 含、end 不含区间内累积毫米，不是瞬时强度；不同区间不能直接相加或比较。station_id 位置随 position_version 变化；每个 reading 显式引用对应位置版本。quality 只允许 valid、suspect、missing；缺测 rain_mm 为 null，0 为有效零雨。process_id 表示同一连续降雨过程，不等于独立样本。

## 现行摘要

`rainnet/analysis.py` 的 `summarize` 生成现行资料摘要，`point_totals` 与 scope 保持原有含义，不能把未提供的推断当成已有能力。

## 村域面积分析

`analyze_area` 使用同一代 stations、readings、villages 生成面积口径分析，不跨代混合：

- **过程相对口径**：跨站比较必须有共同累积区间。分析从各过程相对起点的观测边界中挑选、按可支撑村域覆盖面积最大者自动选择，规模较大的资料会限制候选数量。其他候选口径的支撑情况也一并输出。
- **取值**：只有恰好铺满口径的连续 valid 观测链才得到累积值。更长、更短、有缺口、重叠、缺测或可疑的链都返回不可用原因，不截取、不折算、不插值。
- **面积权重**：村域矩形内按最近站分区（泰晤士多边形）的面积占比。坐标重合的站先合并，避免同一点重复计权；只有一个位置时整村归该位置并标为单站支撑。
- **覆盖**：`coverage` 是有可用观测的村域面积占比。低于阈值视为无法推断；小于 1 时只报告覆盖面积上的均值；只有单站时明确标成点值外推，不能称为村内均匀降雨。
- **位置变动**：position_version 与其有效期单独处理，只有有效期完整包住口径区间的位置才参与该过程；迁移前后不合并，停测不补值，晚启用导致该村部分过程不可估计。
- **空间相关**：同一 process_id 的站间观测属于同一降雨过程且随距离相关，不作为独立样本。空间方差取同过程内站间差异，站间相关用指数距离模型拟合，区间用设计效应放大；过程数增加不会按时间收窄该近似区间。

## 供数接口

`GET /manifest` 返回 generation、tables（每表 count 与 sha256）及 metadata。`GET /tables/<name>?generation=<generation>` 返回同代 rows。供数换代时旧 generation 返回 HTTP 409，不允许将新代记录接入旧分析；不存在的表返回 404。表内容为稳定键唯一的完整同代记录，不是增量事件流。客户端对清单摘要进行核验。摘要使用 UTF-8、排序对象键、紧凑 JSON 的 SHA256，数组顺序保留供数端顺序。

字段与主键声明位于 `rainnet/schema.json`，合成资料位于 `fixtures/dataset.json`。`metadata.cutoff` 是供数展示截点，不自动为分析选择训练截止点。服务可将整个 dataset 原子替换为新一代，但不在同一 generation 下更改内容。

## 结果保存

`reports.py` 保存现有摘要及来源表摘要，report_id 是内容摘要，不是随机编号。相同内容生成相同编号，临时文件写入完成后原子替换目标文件；历史内容是否保留由调用者选择不同目标路径。面积分析使用独立的 `village_area_analysis` 报告种类与 `load_area_report` 校验，原有摘要报告仍由 `load_report` 读取，互不替代。服务只监听本机，不接入生产系统。
